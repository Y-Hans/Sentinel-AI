# URL-ML V4 Adversarial Report

The existing adversarial families were retained as a protected diagnostic suite; no adversarial row was used in V4 fitting or threshold selection. The V4 character models and deterministic models were not promoted because the hard-source failure is already catastrophic at the benign-rejection gate. Existing V3 adversarial evidence remains the applicable family-level baseline while a new safe adversarial evaluation harness is pending.

Observed V4 limitation: structural and character features improve ordinary source-disjoint classification but can assign high malicious scores to legitimate hard-source provider URLs. This is a false-positive/generalization failure, not a single attack-family miss. No claim of adversarial readiness is made.
